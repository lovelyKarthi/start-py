Python Master Pack - Ordered from very basic to advanced.
Folders:
00_basics -> Hello world, installation, python REPL, interpreter tips
01_control_flow -> conditionals, loops, comprehensions
02_data_structures -> lists, dicts, sets, tuples, collections
03_functions_modules -> functions, args, kwargs, modules, packages
04_oop -> classes, dataclasses, inheritance, slots, protocols
05_exceptions_context -> error handling, context managers
06_file_io_data -> CSV, JSON, Excel, pathlib, streaming
07_concurrency_async -> threading, multiprocessing, asyncio, patterns
08_networking_api -> requests, httpx, sockets, retries
09_web_frameworks -> Flask, FastAPI, auth examples
10_databases -> sqlite/sqlalchemy, migrations, transactions
11_testing_ci -> pytest, mock, tox, github actions
12_performance_debug -> profiling, memory, caching
13_security_best_practices -> secrets, input validation, dependencies
14_packaging_deploy -> pyproject, docker, helm basics
15_patterns_architecture -> design patterns, hexagonal, event-driven
cheat_sheets -> pocket references and printable PDFs

All examples are commented and intended to be runnable where dependencies are installed.
